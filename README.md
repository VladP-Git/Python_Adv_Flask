# Python_Adv_Flask
ICH - Python Advanced

Django & Flask:

Разработка масштабируемых веб-приложений и RESTful API на фреймворках Django (DRF) и Flask. 

Глубокая экспертиза в проектировании баз данных и работе с ORM (SQLAlchemy, Django ORM). 

Опыт реализации систем безопасности (JWT, аутентификация), настройки асинхронных уведомлений (сигналы, Email) и интеграции Pydantic для валидации данных
